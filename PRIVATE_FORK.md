# Private desktop candidate

This private repository, `rafamarqqqs/herdr-hi3`, preserves the independent hi3 Tauri prototype and its custom Herdr runtime source. Start with [desktop/README.md](desktop/README.md) for its features, isolation, build requirements and limitations. The [app/](app/) tree is the inherited Ghostty app reference; it is not the hi3 frontend.

The runtime and historical app retain [Herdr](https://github.com/herdrdev/herdr) history and the [Apache-2.0 license](LICENSE). The separate native migration reference is [herdr-native](https://github.com/rafamarqqqs/herdr-native).

Publication does not install an app, start or replace a server, attach to existing sessions or publish a release. Runtime resources, build outputs, local configs and backups are excluded. Initial repository Actions are disabled.
