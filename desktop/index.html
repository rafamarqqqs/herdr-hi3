pane keybinds

Mod = ⌘⌥ (Command + Option). Only inside hi3.

Mod + arrows / J K L ;
Focus left / down / up / right.
Mod + Shift + direction
Move beside the neighboring pane.
Mod + H / V
Choose the next split: side by side / stacked.
Mod + Enter
Create a pane using the chosen direction.
Mod + F
Toggle pane zoom (not macOS fullscreen).
Mod + R
Resize mode: arrows adjust by 5%; Esc/Enter exits.

No close/kill shortcut. Demo supports focus and zoom; mutations require returning to the test server. Parent containers, stacking and tabbed layouts are not implemented yet.
